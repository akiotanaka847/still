# Guía de mecánicas — fuente de verdad del dominio

`Tipos de Mecánicas promocionales.pdf` es el documento de OXXO que define QUÉ es
cada mecánica de promoción. Se guarda en el repo a propósito: el motor
declarativo (`static/js/promo_flow.js`) es en buena medida una **transcripción**
suya, y sin él las declaraciones parecen arbitrarias.

**Si hay que decidir algo sobre mecánicas, la guía manda.** Ya pasó dos veces que
una regla escrita "por intuición" clasificaba mal y la respuesta estaba textual
en el documento:

- Página 1: *"Simple: 1x — Multiple: 2x 3x 4x…"*. El multiplicador de UNO es
  simple. Sin eso, seis promos declaradas simples se clasificaban como múltiples.
- Página 3: en promociones con **alcohol** no se pueden usar "Compra", "Llévate"
  ni "Gratis". Es cumplimiento, no estilo.

## Qué contiene, por página

| pág. | contenido |
|---|---|
| 1 | Las 4 familias: Simple, Múltiple, Promopack, Comunicación de imagen |
| 2 | Simple a precio, con 0/1/2 textos de apoyo |
| 3 | Simple con descuento, segundo conector, **y la regla de alcohol** |
| 4 | Múltiple por cantidad (`3x2`) y por precio (`2x$40`) |
| 5-6 | Las cuatro formas de Promopack |
| 7 | Comunicación de imagen y de precio regular |
| 8 | Cíclicas (orden de los días) — todavía sin implementar |
| 9-10 | Reglas de composición: plecas y arte al final, "BOTELLA Y N COMPLEMENTOS" al inicio |
| 11 | **Catálogo de plecas y textos de apoyo**, con la mecánica donde aplica cada uno. Es la lista exacta de imágenes que hay que subir a la biblioteca. |
