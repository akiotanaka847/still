Still perfect. Every time.

Sube tu Excel y Still arma la pieza sobre la plantilla: una fila = una promo. Descarga en PNG, SVG o PSD por capas.

1

Plantilla y datos

Si tu Excel trae la columna ORIENTACION (H o V), manda el Excel y cada fila usa la plantilla que le corresponde — un mismo archivo puede mezclar verticales y horizontales. Esta selección solo se usa para las filas que no la traigan.

Datos encontrados

Selecciona un Excel para ver los datos de la promoción.

2

Imágenes de marca

En el Excel, las columnas CALLOUT y BRAND se escriben con el nombre del archivo (por ejemplo RUFFLES.SVG). Si el nombre no está acá, la promo sale con la imagen de error.
